# Installation

## Stable release

To install Care Demo Facility Setup, run this command in your terminal:

```sh
pip install Care Demo Facility Setup
```

## From source

The source files for Care Demo Facility Setup can be downloaded from the [Github repo](https://github.com/ohcnetwork/care_demo_facility_setup).

You can either clone the public repository:

```sh
git clone git://github.com/ohcnetwork/care_demo_facility_setup
```

Or download the [tarball](https://github.com/ohcnetwork/care_demo_facility_setup/tarball/master):

```sh
curl -OJL https://github.com/ohcnetwork/care_demo_facility_setup/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd care_demo_facility_setup
pip install .
```
